# UHOME CLUB

Приложение клуба резидентов, которые живут между странами. Собрано из двух
приложений этого репозитория: **структура — от И АЙ КЛАБ** (главная с картой
резидента, ближний круг, события, люди и знакомства, база), **оформление — от UPASS**
(обсидиан и шампанское золото, карта резидента латиницей, живой блок, карта мира).
Функциональность упрощена: только то, чем пользуются каждый день.

**Дизайн.** Спокойный графит и один фирменный акцент — песочное золото; мятный — только
для состояний «вы идёте», «онлайн», «бонус». Выбранное в фильтрах подсвечивается светлым,
действие — золотом. Шрифты — Onest (текст и цифры, с родной кириллицей) и Unbounded
(заголовки вкладок и знак UHOME), оба лежат внутри приложения и работают офлайн
(лицензия SIL OFL, тексты в `uhome/src/fonts/`). Вместо эмодзи — иконки на мягком тоне,
аватары — плашка цвета роли с инициалами.

**Открыть:** https://emorozoff.github.io/evaspace/uhome/

Ставится на телефон как приложение: iPhone — Safari → «Поделиться» → «На экран “Домой”»,
Android — Chrome → «Установить приложение». Работает без интернета (кроме курсов валют).

## Пять вкладок

| Вкладка | Что внутри |
| --- | --- |
| **Главная** | Сверху — регион «Я сейчас» (меняется одним нажатием), сообщения и профиль. Карта резидента из UPASS: качается, переворачивается, на обороте пропуск с кодом. Живой блок листается сам и пальцем: **время** в трёх городах (по умолчанию Москва, Бали, Дубай) и **курсы** (USD→RUB, USD→IDR, BTC→USD). Нажатие на город или курс открывает список — выбранное встаёт на это место. Дальше **ближний круг**: первой команда клуба, но кто написал и не прочитан — поднимается в начало со счётчиком, как в мессенджере. Потом **ближайшие события** региона и эфиры, **новые резиденты**, **новости** |
| **События** | Полноценная афиша. Фильтр в одну строку: регион списком (все, Москва, Бали, Дубай, Майами, Европа, онлайн) и тип (все, закрытые, партнёров). Ближайшее — большой карточкой, остальное — по календарным неделям. Страница события: время в вашем поясе, место с картой, цена, кто ведёт, партнёр, программа, кто идёт, «Иду» / «Подать заявку» на закрытое, файл в календарь |
| **Услуги** | Маркетплейс только из компаний резидентов: визы (Amazonki), байки (Butler Bike), недвижимость, детский сад, рестораны, услуги. Категории плитками, рекомендации региона, поиск. Карточка компании: что предлагают и почём, бонус для резидентов, как это работает, владелец, отзывы, события. Заявка уходит владельцу в личные сообщения |
| **Люди** | Три вкладки. **Знакомства** — механика клуба: подборка из семи человек в неделю, «Познакомиться» или «Пропустить», взаимно — открывается чат. **Резиденты** — вся база с совпадением, регионом и ролью. **Карта** — из UPASS: все регионы сразу, нажатие на регион или приближение показывает людей дугой над значком |
| **База** | **База знаний** — записи Zoom-эфиров и гайды: главные мысли текстом, таймкоды, спикеры. **Сообщества** — пять локальных (Москва, Бали, Дубай, США, Европа; своё — первым) и пять по интересам, у каждого чат и ближайшие встречи |

**Главная привязка — регион.** Где резидент сейчас (Москва, Бали, Дубай, Майами, Европа)
видно на карте резидента, от него зависят афиша на главной, порядок услуг, своё сообщество
и «вы здесь» на часах и карте. Меняется на главной, в профиле и на карте людей.

## Что работает по-настоящему

- **Время** считает браузер по поясам IANA — летнее время в Майами и Европе переключается само.
- **Курсы валют** приходят из открытых источников (Coinbase, запасные — open.er-api и CoinGecko)
  и обновляются раз в 10 минут. Без сети показывается последний полученный курс,
  а если его ещё не было — ориентир с пометкой «примерный курс — нет связи».
- **Совместимость** считается встречно: он даёт то, что вы ищете, и наоборот; общие интересы,
  цели и регион только добавляют. Причины совпадения видны в профиле.
- **Файл в календарь** (.ics) — событие ложится в календарь телефона с правильным временем.
- Всё, что резидент меняет (регион, часы, курсы, круг, записи на события, заявки, переписка),
  хранится на телефоне в `localStorage` под ключом `uhome.v1`.

## Чего пока нет

Настоящего входа, сервера и общей базы, живой переписки между телефонами и записей эфиров
(кнопка «Смотреть» в демо честно говорит, что записи нет). Резиденты, компании, события,
новости и отзывы — демонстрационные: имена, владельцы, тексты и цены придуманы.
Amazonki и Butler Bike названы по вашей просьбе, их описания — заглушки, которые стоит
заменить текстами самих компаний.

## Как устроен код

```
uhome/
├─ index.html            точка входа
├─ public/               иконки, манифест, service worker (область — только /evaspace/uhome/)
└─ src/
   ├─ data/              регионы и города часов, валюты, резиденты, события, услуги,
   │                     база знаний, сообщества, новости, переписки, карта мира
   ├─ lib/               стор (store.jsx), выборки (select.js), совместимость (match.js),
   │                     курсы (rates.js), время (time.js), календарь (calendar.js)
   ├─ components/        карта резидента, живой блок, ближний круг, карта мира,
   │                     обложки, шторки и общие элементы
   └─ screens/           экраны
```

Контент правится в `uhome/src/data/`: например, новая компания — одна запись в `services.js`,
новая валютная пара — одна строка в `currencies.js`, новый город для часов — в `regions.js`.

```bash
npm install
npm run dev:uhome      # http://localhost:5175/evaspace/uhome/
npm run build:uhome    # сборка в dist-uhome/
```

## Публикация

Пуш в ветку `claude/laughing-albattani-ablgxw` запускает `.github/workflows/uhome.yml`:
сборка кладётся **только** в папку `/uhome/` ветки `gh-pages`, соседние приложения не трогаются.
Service worker Eva Space в корне сайта обслуживает всю папку `/evaspace/` — workflow дописывает
`uhome/` в его список соседних приложений, иначе он подменял бы UHOME своей оболочкой.
