# UHOME CLUB · дизайн v4 — «технологии клуба»

Клуб предпринимателей, которые живут между странами. Интерфейс должен ощущаться как
приборная панель из будущего: точный, лёгкий, живой. Не «громоздко», не «жёлтые кнопки».
Референс по духу — инвестиционная презентация UPASS (тёмная колода, тонкие золотые линии,
моноширинные подписи, паспорт с гильошем, всё выезжает и проявляется).

## Принципы

1. **Свет, а не заливка.** Золото — это кромка, свечение, тонкая линия, цифра. Золотых
   плашек и жёлтых кнопок нет. Главная кнопка — тёмное стекло с золотой кромкой (`.btn--gold`).
2. **Тонкие линии вместо тяжёлых карточек.** Панели — почти прозрачные (`var(--panel)`)
   с линией 1px (`var(--line)`), радиусы 10–16px, отступы плотные.
3. **Моноширинные подписи.** Всё служебное — IBM Plex Mono, верхний регистр, разрядка:
   подписи секций, метки, коды, проценты, счётчики, даты (`.eyebrow`, `.hdr`, `.tag`,
   `.sect__note`, `.sect__more`, `.stat__l`, `.kv__k`, `.label`).
4. **Заголовки — Onest.** Страница — `.h1` 28/600, секция — `.sect__title` 18/600,
   торжественный крупный текст — `.hero` (Onest 300 34px, акценты `<b>`).
   Prata (`.display`) — только имена на паспорте, имена Евы и Адама, торжественные моменты.
5. **Движение осмысленное.** Экран въезжает с фокусировкой (`rise`), секции проявляются при
   прокрутке (`.reveal`, у `.stack-24 > .sect` — автоматически), выбор «собирается»,
   цифры досчитываются, линии прорисовываются. 200–600мс, `var(--ease)`, пружина
   `var(--spring)` для щелчков. Всегда уважать `prefers-reduced-motion`.
6. **Одна мысль — один экран.** Карточка знакомства умещается в экран без прокрутки.
7. **Флаги — только `<Flag cc="…"/>`** (components/Flag.jsx). Эмодзи-флаги запрещены:
   на Windows они превращаются в буквы «ID», «RU». Код страны — `REGIONS[k].cc`,
   для часов — `CITIES[k].cc`. Подпись с флагом — `<Place cc>` или `<Flag/> Текст` в JSX.

## Компоненты (готовые классы)

- Кнопки: `.btn` + `--gold` (главная, стекло с кромкой и бликом), `--ghost`, `--quiet`,
  `--done`, `--sm`, `--wide`. Максимум одна `--gold` на экран.
- `.card`, `.card--gold`, `.card--sea`, `.list` + `.item`, `.note`, `.stats` + `.stat`,
  `.kv`, `.chip`/`.chip--on`, `.tag` (моно), `.seg` (золотая черта под выбранным),
  `.picker`, `.field`, `.search`, `.sheet`.
- `Top` (UI.jsx) — моно-строка «UHOME CLUB» с огоньком + заголовок; `eyebrow` можно задать.
- `Section` — заголовок, моно-пояснение, моно-ссылка «ЕЩЁ →» справа.
- Аватары людей — `Avatar` (Art.jsx), групп — `GroupAva`, Евы/Адама — `AvatarPortrait`.

## Как добавлять стили

Общая система — `src/styles.css`. Каждая область пишет свои стили в свой файл
`src/styles/<область>.css` (они подключены после общего и могут переопределять его):
`home.css`, `people.css`, `base.css`, `onboarding.css`, `screens.css`.

## Тексты

Русский, на «вы» (это ещё и нейтрально по роду — пол пользователя не угадываем).
Коротко, без канцелярита. Данные демонстрационные — не выдавать выдуманное за точные
цифры (помечать «ориентир», «примерно»).
