# UPASS — приложение кооператива

Цифровой паспорт резидента, сеть UHOME, доля в активах через UHT, репутация на цепочке
хешей и общее управление. Собрано по техническому заданию — [`docs/upass-tz.md`](docs/upass-tz.md).

**Открыть:** https://emorozoff.github.io/evaspace/upass/

На iPhone: Safari → «Поделиться» → «На экран Домой». Приложение откроется на весь экран,
с иконкой-печатью и офлайн-режимом.

Первый экран предлагает два входа: **«Подать заявку»** — пройти онбординг как настоящий кандидат
(анкета из пяти шагов → модерация → оплата взноса → посвящение и выдача паспорта), либо
**«Войти демо-резидентом»** — сразу оказаться внутри с заполненным профилем, долей и историей.

## Что здесь работает по-настоящему

Не макеты — считающий код.

**Экономика токена.** Цена UHT нигде не задана вручную: `lib/nav.js` считает NAV как
стоимость активов плюс деньги минус обязательства и делит на количество токенов в обращении.
Взнос выпускает токены по текущей цене, и цена после выпуска не меняется — деньги и токены
входят в одинаковой пропорции. Экран показывает это на ваших числах.

**Разбор критической точки ТЗ.** Кнопка «Почему не сначала 1000 токенов, потом 900» строит две
модели на одинаковом потоке взносов и одинаковом росте активов: при выпуске по NAV разрыва нет,
при фиксированном правиле к восьмому взносу участник платит вдвое больше, чем стоит его доля.
Разрыв считается, а не нарисован.

**Цепочка репутации.** `lib/chain.js` — собственная реализация SHA-256 (проверена на контрольных
векторах), никакой сети и никаких зависимостей. Каждая запись хранит хеш предыдущей, корень дня
считается от всей цепочки. Кнопка «Подделать запись» меняет одну запись — приложение показывает,
на каком месте всё разошлось.

**Правило видимости.** Одно правило из ТЗ применено везде: резидент с уровнем выше вашего не
виден нигде — ни в справочнике, ни в городе, ни в составе круга, ни в списке участников события.
Приложение честно сообщает, сколько профилей и событий скрыто, но не показывает их.

**Карта.** Маска суши получена офлайн из Natural Earth и вшита в код двумя килобайтами base64.
Никаких тайлов, ключей и запросов в сеть: точки, проекция и расстояния считаются на месте
(Москва → Бали = 10 038 км).

**Вся графика — вектор из семени.** Гильош на паспорте — эпитрохоида, печать, псевдо-QR, обложки
локаций и услуг, аватары, графики. Ни одной внешней картинки: грузится мгновенно, работает офлайн.

## Тайный слой

ТЗ описывает пять уровней членства. Идея заказчика — три известных всем уровня, а дальше
закрытые. В приложении это разведено на две шкалы:

- **Уровень членства** покупается: Passport, Expert, Business, Gold, Black. Это доступ и коммерция.
- **Степень** зарабатывается встречами, поручительствами и проведёнными событиями.
  Публично объявлены три: Неофит, Резидент, Хранитель. О существовании следующих известно
  из устава, но их названия и состав не публикуются.

Вход в закрытый контур: раздел «Клуб» → три нажатия на печать → назвать последнее слово девиза.

<details>
<summary>Ответ и устройство загадки</summary>

Девиз на печати — `EX UMBRA IN ·····`, последнее слово `LUCEM` (принимается и `ЛУЦЕМ`).
Подсказка лежит в открытом доступе: пять традиций в кодексе стоят в порядке, первые буквы
которого складываются в **Л·У·Ц·Е·М**. Загадка решается без внешних знаний, но только тем,
кто прочитал устав.

</details>

## Как устроен код

```
upass/index.html            точка входа второго приложения репозитория
src/upass/
├─ data/
│  ├─ world.js              маска суши, проекция, расстояния
│  ├─ places.js             20 городов и 20 локаций UHOME
│  ├─ people.js             24 резидента: роли, таланты, репутация
│  ├─ life.js               события, круги, чаты, услуги, поездки, номинации
│  ├─ capital.js            активы, казна, история NAV, выплаты, предложения DAO
│  └─ canon.js              уровни, степени, законы, традиции, ритуалы, база знаний
├─ lib/
│  ├─ nav.js                NAV, выпуск, выкуп, сравнение моделей
│  ├─ chain.js              SHA-256 и цепочка репутации
│  ├─ select.js             выборки и правила видимости
│  ├─ art.js                гильош, псевдо-QR, MRZ, номера резидентов
│  ├─ store.jsx             состояние приложения и localStorage
│  ├─ router.jsx            маршрутизация по hash
│  └─ format.js             деньги, даты, склонения
├─ components/              UI-кит, иконки, генеративная графика, паспорт, карта мира
└─ screens/                 21 экран
```

Состояние живёт в браузере (`localStorage`, ключ `upass.v1`): сервера нет, у каждого своя история,
очистка данных браузера сбрасывает прогресс. Сброс вручную — в профиле.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173/evaspace/upass/
npm run build      # сборка обоих приложений в dist/
npm run preview
```

В репозитории живут два приложения: Eva Space по адресу `/evaspace/`
и UPASS по адресу `/evaspace/upass/`. Одна сборка, один деплой.

## Чего пока нет

Это прототип продукта, а не производственная система. Нет сервера, базы, настоящей оплаты,
живого чата между устройствами и юридической структуры — именно в этом порядке ТЗ и предлагает
их добавлять. Содержимое демонстрационное: имена, компании, суммы и оценки выдуманы, платежи
не проводятся, реестр токенов ведётся в браузере.

Ближайшие шаги по этапам из раздела 12 ТЗ: PostgreSQL с правилами доступа на уровне строк и
тестами видимости, ручная модерация заявок, платёжный провайдер по региону, английская
локализация, и только затем — токенизация первого объекта поверх уже работающего бизнеса.
