# Как поставить обновление на хостинг

Этап 1: вход, пароли и права. Заливаются три файла, данные и контент остаются на месте.

---

## Перед началом: копия

Файловый менеджер хостинга → папка сайта → скачайте на компьютер:

- `data/db.json` — вся база: контент, аккаунты, заказы
- `index.html` и `api.php` — старые версии, чтобы было чем откатиться
- папку `uploads/` — фотографии (можно один раз, они не меняются)

Без этой копии дальше не идите. Занимает две минуты.

---

## 1. Залить три файла

Из этого репозитория — в папку сайта, поверх старых:

| Файл | Что делает |
| --- | --- |
| `index.html` | приложение: вход и регистрация теперь идут через сервер |
| `api.php` | сервер: пароли, права, сессии |
| `.htaccess` | закрывает от посторонних базу, её копию и файл настроек |

Папки `data/` и `uploads/` **не трогайте** — там ваш контент.

## 2. Назначить себя администратором

Откройте в браузере **вашсайт/api.php?action=diag** — при первом обращении сервер сам создаст файл `data/config.php`.

Теперь откройте этот файл в файловом менеджере и впишите свою почту:

```php
return [
  'admins' => [
    'moya@pochta.ru',
  ],
];
```

Почт может быть несколько, каждая на своей строке в кавычках и с запятой. **Права администратора выдаются только так** — ни через приложение, ни паролем их больше не получить.

Изменения подхватываются в течение пары секунд.

## 3. Войти

Откройте сайт → внизу **«Вход для администраторов и экспертов»** → почта из `config.php` и пароль.

- Если аккаунт с этой почтой уже был — **войдите старым паролем**, он продолжает работать. Сервер сам переведёт его на надёжное хранение при первом входе.
- Если аккаунта не было — сначала зарегистрируйтесь в приложении обычным способом, потом войдите через служебный вход.

## 4. Проверить, что всё встало

В панели сверху есть строка состояния — нажмите её, откроется **«Состояние сервера»**. Должно быть:

- Связь с api.php — есть
- Запись в data и uploads — работает
- Администратор назначен — да
- Твои права — администратор

Потом проверьте главное: добавьте материал, обновите страницу, откройте сайт с телефона. Контент на месте — значит всё хорошо.

---

## Что изменится для тех, кто уже пользуется

**Всех попросят войти заново.** Раньше приложение помнило вход записью в браузере, теперь нужен вход с паролем — сервер выдаёт ключ сессии. Прогресс, баллы и программа при этом сохраняются: они подтянутся сразу после входа.

Пароли у всех прежние.

## Если что-то пошло не так

Залейте обратно старые `index.html` и `api.php` из копии — сайт вернётся к прежнему состоянию за минуту. База при этом не пострадает: её формат не менялся, только добавились поля.

---

## Сразу после установки — два дела

**Включить HTTPS.** Панель InfinityFree → SSL-сертификат для домена (бесплатный). Пока сайт работает по `http://`, пароли идут по сети открытым текстом, а установка приложения на телефон вообще не работает — браузеры разрешают её только на защищённых сайтах.

**Удалить `check.php`,** когда закончите с тестами. Он показывает посторонним, как устроен сервер. Его работу теперь делает `api.php?action=diag`, и тот лишнего не показывает.

---

## Чего этот этап ещё не закрывает

**Письма с кодом подтверждения не отправляются** — почтовый сервис не подключён, код по-прежнему показывается на экране. Значит, любой может зарегистрироваться на чужую почту и сам себя подтвердить. Чинится подключением рассылки: Resend, Unisender, SMTP хостинга. Отдельная задача.

**Восстановление пароля не работает** — кнопка «Забыла пароль» показывает сообщение и ничего не делает. Тоже упирается в рассылку писем.

**Хранение в JSON-файле.** Как и раньше: на первые сотни пользователей хватит, дальше нужна база MySQL. Переписывается только `api.php`.

---

## Что где хранится

| Где | Что |
| --- | --- |
| `data/db.json` | контент, курсы, товары, аккаунты, заказы, сессии |
| `data/db.backup.json` | копия, сервер делает её сам перед каждой записью |
| `data/config.php` | почты администраторов |
| `uploads/` | загруженные фотографии |
| браузер пользовательницы | её прогресс — и он же дублируется на сервер по адресу почты |

Резервная копия из приложения: строка состояния → «Скачать резервную копию». Токены входа в копию не попадают.
