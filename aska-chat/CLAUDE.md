# АСЬКА с сервером — мессенджер для друзей Егора

Настоящий мессенджер (сервер, сквозное шифрование, пуши на iPhone) в дизайне «Аськи». Адрес: **https://aska.tytproai.ru**.
Соседняя папка `aska/` — сама «Аська» (демо в браузере с ботами, публикуется на GitHub Pages). Этот мессенджер берёт из неё дизайн.
Егор сам не программирует: всё делает Claude, Егору — объяснять простыми словами, от него только проверка на iPhone.

## Как выкладываются изменения (главное для облачной сессии)
1. Изменения в `aska-chat/` (или в дизайне `aska/*.css`, `aska/icons/`, `aska/sounds.js`) коммитятся и пушатся в ветку `claude/pensive-davinci-tyahht`.
2. GitHub Actions, workflow `.github/workflows/aska-chat.yml`: **проверки** (`npm ci`, `npm test`, `npm run build` в `aska-chat/`) → **выкладка**: сервер сам скачивает эту версию с GitHub, собирает Docker-образ и перезапускает контейнер `aska`. Если новая версия не ответила — сервер возвращает прежнюю. База и фото не трогаются.
3. Через 2–4 минуты изменение на https://aska.tytproai.ru. Какая версия выложена: `https://aska.tytproai.ru/api/health` → `version` = sha коммита.
- Перед пушем запускать `cd aska-chat && npm ci && npm test && npm run build` — упавшие проверки не выложатся.
- Выкладывается только **вершина** ветки. Если запушить два коммита подряд, выложится последний.
- Сервер, Caddy, DNS, ключ выкладки — не в репозитории и меняются только с Mac Егора (локальная сессия Claude Code). Из облака их не трогать и не пытаться заходить на сервер.
- Секрет `ASKA_CHAT_DEPLOY_KEY` в настройках репозитория — ключ выкладки. Его не трогать, не печатать, в коде не использовать.
- Репозиторий публичный: никаких паролей, ключей и личных данных в коде.

## Решения (16.10.2026)
- **Основа — мессенджер «Свои»** (`~/Desktop/Claude Code/мессенджер` на Mac Егора, chat.tytproai.ru): тот же код, другой дизайн, отдельный контейнер и отдельная база. Изменения «Своих» сюда сами не попадают и наоборот.
- **Дизайн — из «Аськи», оба варианта: «Зумер» (стекло Aero 2007, по умолчанию) и «Миллениал» (классика 2000-х, окна Windows 98)**, выбор на экране входа и в настройках, как в «Аське».
- У всех iPhone → веб-приложение (PWA) на экран «Домой», не App Store. Пуши — Web Push (iOS 16.4+), только когда приложение открыто с экрана «Домой».
- Один сервер, сквозное шифрование: сервер хранит только шифр и видит лишь кто, кому и когда писал.
- Вход в АСЬКУ — только по одноразовым приглашениям `XXXX-XXXX`; первое приглашение сервер пишет в журнал при пустой базе.

## Вторая версия (21.10.2026): номера, телефоны, круги, Аська, ИИ-люди, личные ИИ
- **Номера АСЬКИ — как автомобильные**: `А 001 МР 777` (777 — Москва), хранятся строкой `А001МР777` в `users.plate` (`server/src/plates.js`).
  Первому зарегистрированному человеку (он же администратор) — `А001МР777`, Аське — `А000МР777`, остальным — случайный свободный из серии (чтобы по номеру не понять, кто раньше пришёл и кто ИИ). Нарисован компонентом `client/src/components/Plate.tsx`.
- **Вход**: телефон, номер АСЬКИ («001», «а001мр», «А 001 МР 777») или старый логин (например, `kirill`) + прежний пароль. **Регистрация**: приглашение → имя → телефон → (код из СМС, если SMS.ru подключён) → пароль → поздравление с номером. Логин больше не придумывают — внутреннее имя делается из номера (`a042mr777`).
- **Восстановление**: «Не помню пароль» → код из СМС (или «Код для входа» от администратора, если СМС нет) → новый пароль и **новые ключи**. Старые копии сообщений этого человека удаляются (их не открыть), старые входы закрываются, прежний открытый ключ остаётся в `users.prev_pks` — у друзей ключ обновляется без тревоги (`mergeUser` в `lib/store.ts`). Аська пишет «С возвращением».
- **Администратор** — `users.is_admin` (первый человек). «Ещё» → «Управление АСЬКОЙ»: ключ Claude, модель, дневной лимит, «Проверить связь», ИИ-люди вкл/выкл, ключ SMS.ru (api_id) и баланс, список людей с «Кодом для входа». Ключи хранятся в базе на сервере (`settings.ai`, `settings.sms`), наружу отдаются только последние 4 знака.
- **Мозг ботов — Claude** (`server/src/ai.js`, официальный `@anthropic-ai/sdk`): по умолчанию `claude-opus-5-5`, можно выбрать Sonnet 5.5 / Haiku 5.5; `effort: low`, ответ строго по JSON-схеме, `fallbacks: "default"` (кроме Haiku), лимит ответов в день (по умолчанию 400). Нет ключа или кончился лимит — Аська и личные ИИ отвечают по шпаргалке (`personas.js`), ИИ-люди молчат и «не в сети». Для проверки дома: `ASKA_FAKE_AI=1` (`fake-ai.js`, на сервере не используется).
  ⚠ Claude API работает не из всех стран: если «Проверить связь» пишет про 403/регион или «нет связи», с этого сервера Claude недоступен — нужен другой сервер или другой поставщик ИИ (решает Егор).
- **Боты** (`server/src/bots.js`) — обычные участники чатов: свои ключи на сервере (`users.bot_sk`), шифруют и читают тем же протоколом (`server/src/seal.js` ≡ `client/src/lib/protocol.ts`). Дела (ответить, поздороваться, объявить) — в таблице `bot_jobs`, переживают перезапуск. Отвечают с «прочитано», «печатает…» и паузами.
  - **Аська** (`kind = 'aska'`) — живой аватар АСЬКИ, честно ИИ: встречает новичков, отвечает, раз в день может сама заглянуть к тому, кто давно молчит (не чаще раза в сутки, после двух безответных — пауза 3 дня), ведёт «Вопрос дня» в круге `circle:q`. При выкладке новой версии один раз пишет всем «Что нового» (ключ `ANNOUNCE` в `bots.js` — поменять, чтобы объявить снова).
  - **ИИ-люди** (`kind = 'person'`, наружу отдаются как `human`) — 7 характеров в `personas.js` (Катя, Димон, Аня, Сергей, Лера, Тимур, Марина): живут по своему расписанию (в сети/не в сети), сидят в кругах, отвечают в личке и в кругах, иногда сами заводят разговор. Включаются администратором (нужен ключ Claude). Игра «Кто здесь ИИ?» объявлена всем (Аська, «Ещё»), угадать — кнопка в профиле, одна попытка (`guesses`). Во всём серьёзном (здоровье, деньги, безопасность, всерьёз просят правду) они признаются, что ИИ; денег, кодов, встреч не просят.
  - **Личный ИИ** у каждого (`kind = 'twin'`, `owner_id`; есть и у ИИ-людей, чтобы не выдавать их). Друзья пишут ему из профиля **открыто или анонимно** (чат `twin:<twinId>:<userId>:o|a`; хозяин в нём не участник и не видит переписку). Кнопки «💐 Комплимент», «🎁 Подарок», «❓ Вопрос» → ИИ передаёт хозяину в беседу с ним (анонимно — без имени). Хозяин отвечает на вопрос — ответ уходит спросившему. Факты о хозяине — `twin_facts` (вкладка «Мой ИИ»: добавить/удалить, «Разрешить анонимно»).
- **Круги** (`kind = 'circle'`, `chats.emoji/about/is_public`): 6 общих (кино, музыка, путешествия, еда, болталка, вопрос дня) + свои (открытые или для своих). Вступить/выйти/создать — вкладка «Круги». «Общий чат» остаётся только для людей.
- **Приватность**: переписка между людьми по-прежнему шифруется на телефоне. Всё, что пишут ботам (Аське, личным ИИ, ИИ-людям, в круги с ними), сервер читает и отправляет в Claude — это написано в «Ещё».
- **Интерфейс**: вкладки «Чаты · Круги · Мой ИИ · Ещё» (на компьютере — кнопки в окне контактов), карточка человека по долгому нажатию/правой кнопке или по шапке беседы (номер, о себе, написать, личный ИИ открыто/анонимно, закрепить, «Человек или ИИ?»), «печатает…» у всех.
- Проверки: `test/v2.test.js` (номера, телефоны и СМС, восстановление, круги, личный ИИ, Аська, ИИ-люди, обновление, формат запроса к Claude).

## Третья версия (22.10.2026): номера-токены («NFT»), аськоины, голд, блокировка, супер-админ
- **Номера — коллекционные токены** (внутри АСЬКИ, не блокчейн): таблица `plates` (уникальный `key`, где кириллица = латиница), история владельцев `plate_history`, у токена номер `#0001`. У человека может быть несколько номеров, основной — `users.plate_id` (копия строкой в `users.plate`). Логика — `server/src/plates.js` (страны, регионы, разбор, редкость, улучшения, витрина) и `server/src/market.js` (владение, голд, аськоины).
  - **Страны и регионы**: Россия (по городам: 77/97/99/177/197/199/777/797/977 Москва, 78/98/178 Петербург, 116 Казань и др.), Беларусь, Казахстан, Армения, Грузия, Германия, США (Калифорния, Нью-Йорк), ОАЭ (Дубай), Великобритания. Номер нарисован как настоящий номер своей страны (`client/src/components/Plate.tsx`). ИИ-люди получают номер своего города (Макс из Минска — белорусский).
  - **Редкость** считается по виду номера (одинаковые цифры, 001/007/777, «зеркальные», одинаковые буквы): Обычный 50, Редкий 150, Эпический 400, Легендарный 1200, Мифический 5000 аськоинов. **Улучшения** (рамка и свечение, остаются у номера при продаже): Серебро 60 → Неон 150 → Голограмма 350 → Платина 800 → Бриллиант 2000.
  - Вкладка **«Номера»**: «Мои» (сделать основным, улучшить, продать/снять с продажи; основной продать нельзя), «Витрина» (популярные номера разных стран, выпускаются один раз — `showcase_v1`), «Рынок» (что продают люди), «Подобрать» (страна → город → буквы и цифры, цена по редкости). Карточка номера (токен, страна, владелец, история) — по нажатию на номер, в том числе в профиле человека.
  - Вход — по **любому** номеру человека, не только основному, и по номеру АМР второй версии, если его пришлось сменить (`users.old_plate_key`).
- **Аськоины** (`users.coins`, журнал `coin_log`): 100 на старт (всем при переходе — один раз, `plates_v3`), +20 за вход раз в день, +50 за приглашённого друга, +15 за угаданного ИИ, начисление админом. Настоящих денег нет.
- **Роли** (`users.role`: `user` | `admin` | `super`; `is_admin` = 1 у admin и super, держится в синхроне):
  - **Голд = админ**: золотая звезда ★ у имени (`<Gold>` в `Plate.tsx`) и **золотая серия АМР** (`А…МР`, золотая рамка). Серия АМР — только у голд и у Аськи (`А000МР777`): купить или получить её обычный человек не может. Назначили голд — получает АМР с теми же цифрами; сняли — золотые номера уходят, остаётся обычный. При переходе на третью версию обычные люди с номером АМР получили номер с теми же цифрами в другой серии (Аська им об этом написала).
  - Админ в «Управлении АСЬКОЙ» → список людей: **«Номер»** (сменить номер человеку: страна, регион, буквы и цифры), **«Аськоины»**, **«Сделать голд»**, **«Заблокировать»**, «Код для входа». Снять голд или заблокировать другого админа может только **супер-админ**; супер-админа — только другой супер-админ.
  - **Блокировка** (`users.blocked_at`): входы закрываются, человек выходит из общего чата и кругов, вход отвечает «заблокирован». Разблокировать — той же кнопкой.
  - **Супер-админ** (`role = 'super'`, номер `А777МР777` или другой свободный АМР). Может всё, что админ, и ещё снимать голд и блокировать админов и других супер-админов (себя — нет). Их может быть несколько.
    - **Ссылка супер-админа** (`server/src/superlink.js`, таблица `super_links`, в базе только отпечаток кода): одноразовая, 7 дней, на один вход. Создаёт админ, пока супер-админа нет, или супер-админ: «Управление АСЬКОЙ» → «Супер-админ» → логин, телефон или номер человека (или новый логин) → «Создать ссылку» → переслать. По ссылке `…/#super=XXXX-XXXX-XXXX` человек входит своим паролем, задаёт новый («Не помню пароль» — новые ключи, как при восстановлении) или, если входа нет, сам придумывает имя и пароль. Уже вошёл тем же входом — окно «Стать супер-админом». Ссылка от админа перестаёт действовать, если тем временем появился другой супер-админ.
    - С Mac на сервере: `docker exec aska node server/src/cli.js super-link <вход или новый логин>` — ссылка от имени первого админа (Егора), действует всегда. Или сразу с паролем: `read -rs P; printf '%s\n' "$P" | ssh -i ~/.ssh/tutproii_deploy root@159.194.237.231 docker exec -i aska node server/src/cli.js superadmin <логин>; unset P` (так же сбрасывается его пароль).
    - **Логины и пароли супер-админов в репозиторий не писать.**
- Аська при выкладке один раз пишет всем про номера и аськоины (`announced_v3`). Новичку — про вкладку «Номера».
- Интерфейс: вкладки «Чаты · Круги · Номера · Мой ИИ · Ещё».
- Проверки: `test/v3.test.js` (номера стран, витрина, покупка, улучшение, продажа, голд, блокировка, супер-админ из консоли, переход номеров АМР), `test/superlink.test.js` (ссылка супер-админа).

## Как устроено шифрование
- У каждого человека пара ключей X25519 (tweetnacl `box`). Секретный ключ не уходит с телефона в открытом виде.
- Сообщение шифруется на телефоне отправителя отдельно для каждого участника чата (и для себя). Внутри шифра — id чата и uuid: сервер не может перенести сообщение в другой чат или подделать отправителя.
- Для пуша отправитель кладёт отдельное короткое зашифрованное превью; service worker расшифровывает его и показывает текст.
- Фото — secretbox со случайным ключом, ключ и SHA-256 внутри сообщения.
- Пароль → scrypt (N=2^15, r=8) → 64 байта: 32 шифруют резервную копию секретного ключа на сервере, 32 — ключ входа (сервер хранит его SHA-256). Забыл пароль — переписку не вернуть.
- Ключи друзей запоминаются при первой встрече; если сервер выдаст другой — предупреждение. Коды безопасности (20 цифр) сверяются при встрече.
- **Шифрование и протокол не менять без крайней нужды**: `client/src/lib/crypto.ts`, `protocol.ts`, серверные проверки в `server/src/app.js`. Сломанный протокол — нечитаемая переписка у всех.

## Устройство
- `server/src/` — Node 24 (встроенный `node:sqlite`), express, ws, web-push, tweetnacl, @anthropic-ai/sdk. `app.js` — API и WebSocket, `db.js` — схема и переход старой базы на новую, `push.js` — пуши, `cli.js` — приглашение, код для входа и супер-админ из консоли, `bots.js` + `personas.js` — боты, `ai.js` — Claude, `seal.js` — шифрование ботов, `phone.js` — телефоны, СМС и коды, `plates.js` — номера, `market.js` — токены номеров, голд и аськоины.
- `client/src/` — React + Vite. `lib/crypto.ts`, `lib/protocol.ts` — шифрование и формат сообщений, `lib/store.ts` — состояние, синхронизация, отправка, пуши, `sw.ts` + `sw-logic.ts` — service worker. Экраны — `components/`, стили — `styles.css`.
- `test/*.test.js` — проверки сервера и шифрования (`npm test`). `test/ui-check.mjs` — прогон интерфейса в Chrome с экраном iPhone (на Mac, нужен локальный Chrome).
- `Dockerfile` — сборка на сервере, контекст — корень репозитория (нужны `aska-chat/` и `aska/`).
- `deploy/caddy.sh` — разовое подключение адреса в общем Caddy (с Mac). `deploy/server/ci-deploy.sh` — копия серверного скрипта выкладки для справки (сервер её из репозитория не берёт).

## Дизайн «Аськи» (как устроено)
- Берётся **как есть** из соседней папки `aska/`: `styles.css` + `aero.css` (оба вида), `art.js` (цветочки, смайлы, конвертик), `sounds.js` («о-оу», голоса смайлов), `icons/`. Перед сборкой `npm run design` (`scripts/copy-aska.mjs`) копирует их в `client/public/aska/` (в git не хранится).
- **Зумер** = `body.skin-aero`, **Миллениал** = `body.skin-classic` (те же файлы, классический вид — это `styles.css`; `aska/v2/styles.css` от него почти не отличается). Выбор — на экране входа и в «Настройках», запоминается в браузере.
- Экраны собраны из тех же классов, что в «Аське»: `.desktop`, `.wins`, `.win.contacts#cwin`, `.win.chat#chatwin`, `.win.aux#auxwin`, `.win.dialog#loginwin`, `.titlebar/.tbtn`, `.me-panel`, `.clist/.cgroup/.citem/.cmeta/.badge`, `.chat-head`, `.history/.msg.me|them/.hdr/.nk/.time/.txt/.grp/.new`, `.compose/.send-row`, `.smiles`, `.tabbar`, `.overlay.sheet`, `.toast`, `.groupbox/.legend`, `.design-pick`, `.uin-box`, `.tabs/.tabpanel`. Переключение экранов на телефоне — классы `mode-chat` / `mode-aux` на `.desktop`, как в «Аське».
- **Правки дизайна делаются в `aska/`** (облачная сессия «Аськи») и сами попадают сюда при следующей выкладке (workflow следит за `aska/*.css`, `aska/icons/**`, `aska/sounds.js`). Если в «Аське» переименовать перечисленные классы или функции `AskaArt.statusFlower/flowerSvg/envelopeSvg/smileSvg/SMILES` и `AskaSound.play/smile/unlock` — поправить и мессенджер.
- Своё, чего в «Аське» нет (фото, ответы, галочки, просмотр фото), — в `client/src/styles.css` с префиксом `aska-`.
- Статус «в сети / не в сети» (зелёный и красный цветок) — сервер шлёт событие `presence`, «не в сети» — через 8 секунд после закрытия приложения.

## Настоящие звуки ICQ
- «Uh-oh» (о-оу) — входящее сообщение, «User is online» — друг появился в сети (плюс всплывашка), перезвон — сообщение отправлено. Оригиналы ICQ 99a, скачаны 16.10.2026 из github.com/Xylemon/AIM-and-ICQ-Sounds-for-Pidgin, опознаны whisper.
- **Права у ICQ, поэтому в публичный репозиторий не кладём.** Файлы — только на сервере в `/opt/aska/sounds`, `ci-deploy.sh` подключает их в контейнер как `/app/client/dist/sounds` (только чтение). Копия на Mac — `aska-chat/private-sounds/` (в `.gitignore`), там же `ОТКУДА.md`.
- Код: `client/src/lib/aska.ts` — `REAL` (имя события → файл), загрузка через Web Audio; нет файла (локально, в облачной сессии) — играет синтезированный звук «Аськи» (`AskaSound`). Звук включается после первого касания (требование iPhone).
- Поменять звук: положить новый WAV/MP3 на сервер в `/opt/aska/sounds` с тем же именем (с Mac) — перевыкладка не нужна.
