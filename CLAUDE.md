# Правила разработки в этом репозитории

В репозитории два самостоятельных приложения на React + Vite, одна сборка и один деплой:

- **Eva Space** — `src/`, публикуется по адресу `/evaspace/`
- **UPASS** — `src/upass/` и `upass/index.html`, публикуется по адресу `/evaspace/upass/`

Точки входа перечислены в `vite.config.js` (`build.rollupOptions.input`). База путей — `/evaspace/`,
поэтому ссылки на файлы из `public/` пишутся абсолютно: `/evaspace/upass/icons/icon-192.png`.

## Общие договорённости

- Язык интерфейса и комментариев — русский. Комментарии объясняют «почему», а не пересказывают код.
- Маршрутизация по hash (`#/path`) — иначе ломаются GitHub Pages и запуск с экрана «Домой».
- Никаких внешних картинок, шрифтов и запросов в сеть во время работы: графика рисуется вектором,
  шрифты лежат в `public/fonts`, данные вшиты в код. Приложение обязано открываться офлайн.
- Зависимости только React и React DOM. Новая библиотека — повод сначала обсудить.
- **Service worker Eva Space видит всю папку `/evaspace/`.** Любое вложенное приложение
  добавляется в список `NESTED` в `public/sw.js`, иначе Eva подменит его своей оболочкой
  при офлайне и испортит собственный кэш. У вложенного приложения — свой манифест
  с `scope`, свой sw.js и свои иконки в `public/<имя>/`.
- Состояние живёт в одном сторе на приложение (`lib/store.jsx`) и сохраняется в `localStorage`
  под своим ключом (`upass.v5`). Компоненты не пишут в хранилище напрямую. Ключ поднимается
  при изменении формы данных — старое состояние не мигрируется.

## Правила UPASS

Приложение про путешествия и сообщества. Токенов, кооперативной собственности,
недвижимости как актива и залов в нём нет — эти сущности удалены сознательно,
не возвращайте их без отдельного решения.

- **Регион — центр модели.** Всё на экранах зависит от `me.city` (ключ региона):
  афиша, сообщества, запросы, услуги. Данные регионов — `data/regions.js`.
- **Стоимость перелёта и жизни считается, а не пишется руками.** Формулы — в
  `lib/travel.js`: время из расстояния, цена из расстояния и ценового индекса региона.
  Правка экономики начинается с данных региона.
- **Доступ решает степень.** Уровень членства на старте один — Travel за $200.
  Все проверки видимости идут через `lib/select.js` (`canSee`, `visibleOnly`) —
  не фильтруйте в компонентах.
- **Журнал репутации — только на добавление.** Записи не редактируются; хеши строятся
  в `lib/chain.js`. Менять формат тела записи (`payload`) нельзя без миграции.
- **Мероприятия бывают офлайн и эфиром** (`online: true`). Заставку выбирает
  `components/Poster.jsx`: силуэт региона или абстрактная графика эфира.
- **Аватар — сквиркл, цвет по роли** (`ROLE_TONE` в `data/people.js`, хелпер `toneOf`).
  Круглых аватаров в приложении быть не должно.
- **Паспорт заполняется латиницей** — это проездной документ, а не карточка профиля.
  Английские подписи берутся из данных (`en` у региона и степени, `ROLE_EN` у роли),
  а не пишутся в разметке.
- **Цифры — гротеском с табличными знаками** (`.stat__v`, `.figure`). Антиква осталась
  заголовкам и имени в паспорте.
- **Круги общения — в `data/circles.js`.** Ближний круг, друзья, бизнес: раскладка по
  умолчанию плюс ручные переносы в сторе. `'none'` означает «убран из кругов» и не даёт
  раскладке вернуться.
- **Фильтров-лент больше нет.** Там, где раньше стояли две строки чипов, стоит `Picker`
  из `components/UI.jsx`: одна кнопка с текущим выбором и список в шторке.
- **Живая строка на главной** (`components/Pulse.jsx`) сама меняет содержимое каждые пять
  секунд каруселью, как табло: уходящий слайд уезжает влево целиком, приходящий
  въезжает справа, и оба живут рядом ровно одну анимацию. Первым идёт перелёт —
  если своя поездка не объявлена, показывается направление из `SUGGEST`.
  Высота фиксирована — иначе экран прыгает на каждой смене.
- **У трёх событий года своя заставка** (`Flagship` в `components/Poster.jsx`):
  глобус с маршрутом у U-connect, сходящаяся схема у U-conf, венок и звезда
  у U-world. Силуэт региона им не подходит — слёты каждый раз в новой стране.
- **Регион открывается сразу.** С карты, с обложки и из списка нажатие ведёт на
  `/region/:key`; промежуточной шторки с расчётом нет — всё это есть на самом экране.
- **Совместимость считается встречно** (`lib/match.js`): мой запрос против его предложения.
  Словарь один на оба вопроса — `data/exchange.js`; у резидентов метки лежат в `EXCHANGE`
  в `data/people.js`. Общие интересы только добавляют, метча сами по себе не делают.
- **Цены проверяются, а не выдумываются.** Аренда, месяц жизни и средний чек — в
  `data/regions.js`, билет считается формулой в `lib/travel.js`. Правка экономики
  начинается с данных региона, а не с коэффициента в формуле.
- **Сетки должны уметь сжиматься.** У `.stack`, `.stack-8`, `.stack-20` и `.sect` есть
  `grid-template-columns: minmax(0, 1fr)` и `align-content: start`. Без первого широкая
  строка растягивает экран, без второго содержимое растягивается по вертикали.
- Данные и текст живут в `data/`, вычисления — в `lib/`, экраны — в `screens/`.
  Экран не должен содержать бизнес-правил, только их отображение.

## Проверка перед коммитом

```bash
npm run build      # обязательно: собираются оба приложения
npm run preview    # и глазами по ключевым экранам
```

Спецификация продукта — `docs/upass-tz.md`, описание реализованного — `UPASS.md`.
Работа ведётся по этапам из раздела 12 ТЗ: один этап — одна ветка.
