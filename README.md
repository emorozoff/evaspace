# Eva Space V2

Платформа женского развития: личная программа на каждый день, практики, курсы экспертов, сообщество и маркет.

**Открыть приложение:** https://emorozoff.github.io/evaspace/

На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой». Приложение появится иконкой со звездой и будет открываться на весь экран, без адресной строки. На Android появится баннер «Установить».

---

## Как устроено

Приложение работает **одним файлом**: вёрстка, стили и логика внутри `index.html` (~590 КБ). Его можно открыть двойным кликом с диска, положить на любой хостинг или, как сейчас, опубликовать на GitHub Pages. Никакого npm.

Но пишется оно по кускам: исходники лежат в `src/`, а один файл собирается командой

```
python3 build.py        # → dist/index.html
```

Так правка одного экрана видна маленьким понятным диффом, а не строчкой «изменён файл на 9 000 строк». Сборщик вставляет куски дословно, ничего не минифицируя и не переставляя, — собранный файл всегда можно прочитать глазами.

| Исходник | Что внутри |
| --- | --- |
| `src/index.template.html` | каркас страницы |
| `src/styles.css` | дизайн-система и все стили |
| `src/app/01-data.js` | контент: уроки, курсы, товары, эксперты |
| `src/app/02-store.js` | хранилище, аккаунты, календари, аватары |
| `src/app/03-core.js` | подбор программы, роутер, перерисовка |
| `src/app/04-auth.js` | вход, регистрация, подписка, загрузка фото |
| `src/app/05-courses.js` | обучение по курсам, чаты, личные сообщения |
| `src/app/06-screens.js` | главная, контент, курсы, маркет, сообщество, профиль |
| `src/app/07-market.js` | отчёты, календари, товары, заказы |
| `src/app/08-admin.js` | админ-панель и кабинет эксперта |
| `src/app/09-sync.js` | синхронизация с сервером и вход по токену |
| `src/app/10-sheets.js` | шторки, действия, запуск |

Порядок загрузки задан номерами в именах — файлы просто склеиваются по порядку.

| Файл | Зачем |
| --- | --- |
| `dist/index.html` | Собранное приложение — этот файл и заливается |
| `build.py` | Сборщик: из `src/` в один файл |
| `api.php` | Серверная часть: аккаунты, пароли, права, хранение контента |
| `.htaccess` | Настройки Apache и защита служебных файлов |
| `manifest.json` | Чтобы приложение ставилось на телефон как обычное |
| `sw.js` | Service worker: приложение открывается и без интернета |
| `icon.svg`, `icon-192.png`, `icon-512.png` | Иконки |
| `INSTALL.md` | Как поставить обновление на хостинг |
| `.github/workflows/deploy.yml` | Автопубликация витрины на GitHub Pages |

Боевая версия живёт на своём хостинге с PHP — там работает `api.php` и общая база.
На GitHub Pages публикуется то же приложение без сервера: удобно посмотреть, но данные
остаются в браузере смотрящего.

Шрифты (Inter, Unbounded) подгружаются с Google Fonts; без интернета подставляются системные.

## Что внутри

**Три роли** — переключатель ролей прямо в приложении (пользователь / эксперт / админ), служебный вход по почте и паролю.

| Раздел | Что можно потрогать |
| --- | --- |
| **Вход и онбординг** | Регистрация с подтверждением почты, тест из вопросов, экран «Ева собирает программу», готовая программа на 7 дней |
| **Главная** | Программа на неделю, аффирмация / практика / мастер-класс на день, звёзды, баллы, бонусы, «мягкий режим» |
| **Контент** | Библиотека уроков: поиск, фильтры по тегам, сортировка по совпадению с тобой |
| **Курсы** | Каталог ровными карточками (обложка и название), страница курса с описанием после промо-ролика. Купленный курс: обложка, эксперт, прогресс с кнопкой «Следующий урок» и уроки по модулям; каждый урок открывается своим окном — видео, описание, домашнее задание, «Урок пройден» и «Следующий урок». Прогресс хранится в профиле женщины, в демо покупка открывает курс сразу |
| **Маркет** | Товары, корзина, вопросы к товару, списание бонусов, заказы |
| **Сообщество** | Группы по интересам, лента, чаты, встречи и события, знакомства |
| **Профиль** | Уровни, накопления, реферальная программа и доход с аудитории, настройки, поддержка |
| **Календарь** | Цикл и фазы, лунный календарь, натальная карта, рекомендации практик под фазу |
| **Отчёт недели** | Звёзды по дням, баллы, минуты практик, разбивка по форматам |
| **Ева** | Помощница по кнопке-звезде: понимает запрос своими словами, подбирает материал, курс, эксперта или встречу, отвечает на частые вопросы и на письма в «Посланиях», сама задаёт вопросы и рассказывает интересное; голосовой ввод и чтение вслух |
| **Адам** | Напарник Евы в «Посланиях»: комплимент дня и слова поддержки — про неё, а не про дела. Пишет раз в день, отвечает на письма, вкладка «Комплимент» в сообщениях |
| **Кабинет эксперта** | Свои курсы и уроки, домашние задания учениц, услуги, публичная страница, почта и пароль |
| **Админка** | Контент, курсы, товары, события, эксперты и доступы, модерация, идеи, статистика |

**Доступ:** первые 3 дня бесплатно, дальше подписка (месяц / год) — оплата демонстрационная.

### Как устроена Ева

Помощница работает целиком в браузере: без интернета, без внешних сервисов и
без платных ключей. Всё живёт в `src/app/17-eva.js`:

- **разбор фразы** — по началам слов, а не по точному совпадению: «устала»,
  «усталость», «устаю» ловятся одной основой. Таблица `EVA_I` — около сорока
  смыслов, у каждого свой ответ;
- **совет** — конкретный материал из библиотеки, отобранный той же оценкой,
  которой собирается программа, и не повторяющийся два раза подряд;
- **её вопросы** — `EVA_ASKS`: каждый ответ что-то меняет (веса тем, мягкий
  режим, длину дел, удобное время), иначе вопрос не нужен;
- **интересное** — `EVA_FACTS` плюс наблюдения из её собственных данных:
  серия дней, звёзды, минуты, любимая тема, сколько до статуса;
- **когда молчать** — сама пишет не чаще двух раз в день и не окном поверх
  экрана: сообщение ложится в разговор, а на звёздочке появляется цифра;
- **чтобы не потерялось** — то же сообщение уходит письмом в «Послания», не
  чаще раза в день. Цифра на звёздочке видна, только пока приложение открыто,
  а письмо дождётся и через неделю: его видно по значку на конверте, и под ним
  стоит кнопка «Ответить Еве»;
- **что в приложении** — мероприятия из календаря, курсы, практики и эксперты
  отдаются карточкой с кнопкой; название курса, практики или имя эксперта во
  фразе важнее общей темы («расскажи про курс деньги без стыда» — про курс);
- **частые вопросы** — `EVA_FAQ`, двадцать с лишним ответов про подписку,
  консультации, настройки, поддержку; панель «?» в окне и разбор своими словами;
- **письма** — на письмо Еве в «Посланиях» отвечает она сама тем же движком;
  каналы Eva Events, Eva Эксперты, Eva Маркет и Eva Space отвечают по-своему,
  а не одним «передали команде» (`chanAck`);
- **голос** — системный синтез речи браузера: лучший из русских голосов,
  чтение по предложениям. Микрофон — браузерное распознавание.

Адам живёт в `src/app/18-adam.js`: тридцать комплиментов и дюжина
вдохновляющих строк, личные наблюдения из её данных, письмо раз в день не
раньше девяти утра, ответы на благодарность, грусть и «ты кто». Правило тона —
без флирта, без сравнений и без внешности: хвалим характер, усилия и выбор.

Если появится ключ к внешней модели, сюда добавится один запрос, а эта логика
останется резервом на случай «нет сети».

## Где живут данные

Приложение при запуске стучится в `api.php` рядом с собой.

- **Сервер есть** (обычный PHP-хостинг) — контент, аккаунты и заказы общие для всех устройств, вверху горит «Данные сохраняются на сервере». Личный прогресс лежит и в браузере, и на сервере по адресу почты, поэтому подтягивается при входе с другого телефона.
- **Сервера нет** (как на GitHub Pages — там PHP не выполняется) — приложение спокойно продолжает работать локально и пишет «Локальный режим: сервер не подключён».

## Про доступ

Вход по почте и паролю. Пароль проверяет сервер (`password_hash`), приложение получает
в ответ токен сессии и предъявляет его при каждом запросе. Общего ключа синхронизации
больше нет.

Права:

- **пользовательница** — свой прогресс, свой профиль, записи в ленту, заказы и вопросы;
- **эксперт** — плюс контент: уроки, курсы, мероприятия;
- **администратор** — всё, включая список аккаунтов и резервную копию.

Администратором становится тот, чья почта вписана в `data/config.php` на хостинге.
Этот файл не попадает в git и закрыт от посторонних. Ни из приложения, ни подбором
пароля права администратора получить нельзя.

Подробности установки — в [INSTALL.md](INSTALL.md).

## Как обновить приложение

1. Правки делаются здесь, в репозитории, а не прямо на хостинге: так есть история и откат.
2. На хостинг заливаются изменённые файлы через файловый менеджер — порядок в [INSTALL.md](INSTALL.md).
3. Витрина на GitHub Pages обновляется сама: GitHub Actions собирает папку сайта и пушит её в ветку `gh-pages`, ссылка оживает через 1–2 минуты.

Контент можно править и без кода — через админку внутри приложения.

Если ссылка отдаёт 404, включите Pages: **Settings → Pages → Source: Deploy from a branch → Branch: `gh-pages` / `/ (root)`**.

## Про контент

Весь контент — заглушки для демонстрации: имена экспертов, названия уроков, тексты, курсы, товары и цены вымышленные. Обложки рисуются вектором прямо в приложении, поэтому грузятся мгновенно и работают офлайн.
