# Eva Space — MVP

Платформа женского развития с индивидуальной программой обучения.

**Открыть приложение:** https://emorozoff.github.io/evaspace/

На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой». Приложение появится иконкой с путеводной звездой и будет открываться на весь экран, без адресной строки.

---

## Что работает в MVP

| Раздел | Что можно потрогать |
| --- | --- |
| **Онбординг** | Имя + 6 вопросов, экран «Ева анализирует твои ответы», результат с процентом совпадения |
| **Подбор программы** | Настоящий алгоритм: ответы → теги с весами → сравнение с тегами 48 уроков → 7 дней по 3 урока |
| **Личный кабинет** | Программа на неделю, аффирмация / утренняя практика / мастер-класс, звёзды, баллы, бонусы |
| **Звёзды** | 3 звезды в день, 21 за неделю → суперзвезда и +200 баллов |
| **Весь контент** | 48 уроков, поиск, фильтры по тегам, сортировка по совпадению с тобой |
| **Курсы** | 8 экспертов, 7 курсов, страницы курса и эксперта, демо-оплата |
| **Маркет** | 14 товаров, корзина, списание бонусов до 30% заказа, демо-заказ |
| **Сообщество** | 6 групп по интересам, лента, свои сообщения, лайки, создание своей группы |
| **Профиль** | Уровни Ученица → Эксперт → Наставница, накопления, реферальная ссылка, «моя аудитория» и % с неё |
| **Календарь цикла** | Фазы цикла, прогноз, рекомендации практик под фазу |
| **Отчёт недели** | Звёзды по дням, баллы, минуты практик, разбивка по форматам |
| **Ева** | Чат-помощник: понимает запрос, подбирает контент, голосовой ввод и озвучка ответов |
| **Админка** | `#/admin`, пароль `eva2024` — добавление уроков и товаров, обзор тегов, пересборка программ |

## Чего пока нет (следующий этап)

Настоящей регистрации, сервера и базы данных, реальной оплаты, живого чата между устройствами, видеохостинга и нейросети внутри Евы. Сейчас всё живёт в браузере телефона: данные сохраняются в `localStorage`, поэтому у каждого свой прогресс, а очистка данных Safari сбрасывает его.

## Про контент

Весь контент — заглушки, придуманные для демонстрации: имена экспертов, названия уроков, тексты аффирмаций, курсы, товары и цены вымышленные.

- **Картинки** не берутся из интернета — каждая обложка рисуется вектором прямо в приложении (12 стилей + оттенок). Поэтому они грузятся мгновенно, работают офлайн и никогда не «ломаются». Если у урока или товара указано поле `image` со ссылкой на фото — показывается фото.
- **Видео** — один свободный ролик-заглушка (`public/video/bloom.mp4`), вшитый в проект. Уроки без видео проигрываются как анимированная обложка с таймером.
- **Заменить контент** можно двумя способами: через админку прямо в приложении или правкой файла `src/data/content.js`.

## Как запустить локально

```bash
npm install
npm run dev      # http://localhost:5173/evaspace/
npm run build    # сборка в dist/
```

## Как устроен код

```
src/
├─ data/content.js      контент: эксперты, уроки, курсы, товары, группы, вопросы онбординга
├─ lib/
│  ├─ matching.js       алгоритм подбора: веса тегов, оценка урока, сборка 7 дней
│  ├─ store.jsx         состояние приложения + сохранение в localStorage
│  ├─ eva.js            сценарии помощника Евы
│  └─ router.jsx        маршрутизация по hash (нужна для GitHub Pages и PWA)
├─ components/          Art (генеративные обложки), иконки, общие элементы, нижнее меню
└─ screens/             экраны приложения
```

## Публикация

Пуш в ветку `claude/eva-space-app-ho4tcy` запускает GitHub Actions: сборка и выкладка готового сайта в ветку `gh-pages`, откуда его отдаёт GitHub Pages.

Если ссылка отдаёт 404 — значит, Pages ещё не включён для репозитория. Включается один раз: **Settings → Pages → Build and deployment → Source: «Deploy from a branch» → Branch: `gh-pages` / `/ (root)` → Save**. Через минуту сайт поднимется, дальше всё обновляется автоматически.
