Штаб Eva Club: конфиденциальность

Внутренний инструмент команды Eva Space · https://eva.tytproai.ru

Для кого

Штаб Eva Club — рабочее приложение команды Eva Space: задачи, собрания, финансы. Пользуются им только члены команды по приглашению.

Что штаб получает из Google

Только если вы сами подключили Google Календарь в разделе «Календарь»:

  • адрес вашей почты Google — чтобы понять, чей это календарь;
  • список ваших календарей и занятость (свободно / занято) — чтобы подбирать время собраний, удобное всем;
  • события, которые создаёт и меняет сам штаб, — собрания команды с приглашениями участникам.

Как используем

Данные календаря нужны только для собраний команды внутри штаба. Мы не продаём их, не передаём третьим лицам, не используем для рекламы и не обучаем на них модели ИИ. Использование данных из API Google соответствует Google API Services User Data Policy, включая требования Limited Use.

Где хранится

Ключ доступа к вашему календарю хранится на сервере штаба и не попадает в браузер других людей. Сами события остаются в вашем Google Календаре.

Как отключить

В штабе: «Календарь» → «Отключить». Или в аккаунте Google: myaccount.google.com/permissions → «Штаб Eva Club» → «Удалить доступ». После этого штаб больше ничего не получает из вашего календаря.
