# И АЙ КЛАБ — приложение клуба

Мобильное приложение клуба: ставится на телефон иконкой, открывается на весь
экран и работает без интернета. Не Telegram Mini App — общение остаётся в
телеграме, а всё, что в чате теряется, живёт здесь.

**Открыть:** https://emorozoff.github.io/evaspace/club/

---

## Как поставить на телефон

| Устройство | Что делать |
| --- | --- |
| **iPhone, iPad** | Открыть ссылку в Safari → «Поделиться» → «На экран “Домой”» → «Добавить» |
| **Android** | Открыть в Chrome → меню из трёх точек → «Установить приложение» |
| **Компьютер** | Chrome или Edge → значок установки справа в адресной строке |
| **APK-файл** | Actions → «Сборка Android APK» → Run workflow → скачать `iai-club-apk` |

То же самое написано внутри: **Профиль → Установить на телефон**. APK собирается
через Capacitor тем же кодом, что и сайт, и подписан отладочным ключом — на
телефоне нужно разрешить установку из неизвестных источников.

## Как устроено

Четыре вкладки: **Главная · События · Команда · Люди**. Профиль — по аватарке
справа сверху, база знаний, рейтинг, город и приглашение — плитками на главной.

**Первое впечатление.** При запуске — короткая заставка: из тонких линий
собирается искра клуба. Показывается один раз за сессию и пропускается тапом.

**Знакомство вместо анкеты.** После регистрации — четыре экрана и семь вопросов,
всё нажатием на плитки с иконками: роль, опыт, сильные стороны (до трёх), возраст,
доход, состояние сердца («сердце открыто», «хочу влюбиться», «уже влюблён»,
«женат / замужем», «всё сложно») и увлечения (до трёх). Роль и опыт нужны куратору,
чтобы команды вышли равными; сердце и увлечения — чтобы люди находили друг друга
на пятницах и рандом-кофе. Доход видит только куратор. Анкету можно перепройти
в профиле.

**Карточка резидента.** Первое, что видно на главной: имя, статус («Резидент» или
«Резидент PRO»), номер, город, команда и полоса сезона. По карточке раз в несколько
секунд проходит полоса света, линии на фоне свои у каждого участника. Под ней —
обратный отсчёт: дней до финала, сколько встреч посетил из скольких, сколько человек
в команде. Ниже — ближний круг: команда попадает туда сама, остальных добавляют плюсом.

**События.** Два клубных события в неделю — вторник (мастермайнд и воркшоп
чередуются) и среда (общий эфир); рядом своя пятница в городе и созвон команды.
Недели разделены заголовками с зазором, созвон показан строкой — у него нет
фиксированного времени. Карточка по механике Евы: обложка 16:10 с типом и названием,
короткое описание, а внизу отдельной строкой — кто идёт и одна кнопка «Пойду».
Аватарки никогда не ложатся на обложку. Обложки рисуются вектором по типу:
эфир — волны сигнала, пятница в городе — вечерние дома, созвон — связанные
узлы, слёт — лучи. За 15 минут до эфира кнопка сама превращается в «Подключиться».
На главной то же событие показано короткой плашкой.

**Команды собирает куратор.** Участник оставляет короткую заявку — роль (уже
подставлена из анкеты), часы в неделю и пару слов о себе. Куратор в админке видит
очередь заявок вместе с ответами анкеты и баланс каждой команды: каких ролей нет,
какие задвоились. Команды, где нужной роли ещё нет, поднимаются в списке первыми.

**Страница команды.** Аватар команды рисуется вектором по её id, рядом — название,
активность и место с кубком. Дальше: цель сезона (её правит капитан), следующая
встреча, состав с ролями, капитаном и помощником, недельный отчёт, записи о выручке
и чат. Капитан меняет роли, назначает помощника и передаёт капитанство.

**Усиление команды.** Любой участник может позвать в команду человека без команды:
тот получает уведомление и решает сам. За каждого пришедшего — 500 ₽ бонусами
пригласившему.

**Люди.** Каталог одним списком с поиском и двумя фильтрами (город, навык),
пара недели по рандом-кофе первой строкой, друзья отдельной вкладкой с входящими
заявками. На странице человека — ряд действий: написать в телеграм, в друзья, кофе.

**Города.** Двое в городе — автоматически чат и еженедельная «Пятница в {городе}»,
первому предлагается стать организатором. Организатор задаёт место и время или
отменяет неделю; без организатора любой участник предлагает место.

**Рейтинг и копилка.** Первые три места — подиум с золотым, серебряным и бронзовым
кубком, дальше медали. В строке команды видны выручка, активность (средняя посещаемость
участников) и часы. Выручка вносится за минуту: частые суммы — одним нажатием, своя
сумма вводится с разрядами (120 000). Правится 48 часов. 10% — взнос в копилку; пока
он не отмечен, эта часть выручки в рейтинг не идёт, а строка подсвечена с пометкой
«не засчитано».

## Дизайн

Тёмные ровные поверхности без обводок, списки как в мессенджере, один заголовок
на экран (Cormorant), возврат подписан словом «Назад», фильтры — одной кнопкой
с шторкой вместо лент чипов, аватары-сквирклы с оттенком от имени. Акцент —
спокойная мята; тёплый янтарь только для денег и мест в рейтинге.

## Чего нет и почему

- **Сервера.** Всё живёт в `localStorage` телефона. Где подключать бэкенд — ниже.
- **Настоящей авторизации.** Код из СМС не проверяется.
- **Оплаты внутри.** По ТЗ оплата снаружи, приложение читает статус. Кнопка «Я оплатил» в демо просто открывает доступ.
- **Личных сообщений.** «Написать» ведёт в телеграм.
- **Своего видеохостинга.** Только ссылки на YouTube, Kinescope, VK Видео, Google Drive.

**Демо-условности:** в одиночном демо некому нажать кнопку за другого, поэтому
куратор распределяет заявку в команду через 20 секунд (в команду, где меньше всего
людей), а заявку в друзья и приглашение в команду демо-участник принимает через 10. С настоящим бэкендом
это делают живые люди: куратор — в админке, участники — у себя.

## Демо-данные

33 участника в 10 городах, 5 команд, записи о выручке, 17 материалов и расписание
на два месяца. Сезон считается от сегодняшней даты, поэтому демо не устаревает.
В Алматы намеренно один участник — зарегистрируйтесь там и увидите, как срабатывает
правило «в городе стало двое». Кнопка **«Посмотреть глазами участника»** пускает
внутрь под любым демо-участником. Сбросить всё: Профиль → «Сбросить демо-данные».
Админка: Профиль → «Админка клуба», пароль `club2026`.

## Как запустить локально

```bash
npm install
npm run dev:club     # http://localhost:5174/evaspace/club/
npm run build:club   # сборка в dist/club/
npm run icons:club   # перерисовать иконки приложения
```

## Куда подключать настоящий бэкенд

Вся работа с данными идёт через один редьюсер в `src/lib/store.jsx`. Чтобы перевести
приложение на Supabase или любой другой бэкенд:

1. Заменить `load()` и `save()` на запросы к базе — имена таблиц совпадают с моделью
   из ТЗ (`users`, `cities`, `events`, `rsvp`, `teams`, `team_members`,
   `revenue_entries`, `contributions`, `materials`, `friendships`, `coffee_matches`,
   `referrals`) плюс `applications` — заявки куратору, `invites` — приглашения
   в команду, `users.facts` — ответы анкеты.
2. Перенести на сервер правила из `src/lib/logic.js`: `ensureCityRules` (двое в городе),
   `ensureCoffee` (пары по понедельникам), `buildNotifications` (рассылка).
   Автораспределение куратора из `tick` в сторе — убрать: это демо-заглушка.
3. Заменить демо-вход в `src/screens/Auth.jsx` на настоящую отправку кода.

Расчёт рейтинга и копилки (`teamStats`, `leaderboard`) переносить не нужно —
это чистые функции.
