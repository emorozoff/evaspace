# И АЙ КЛАБ — приложение клуба

Полноценное мобильное приложение (не Telegram Mini App): ставится на телефон
иконкой, открывается на весь экран и работает без интернета.

**Открыть:** https://emorozoff.github.io/evaspace/club/

---

## Как поставить на телефон

| Устройство | Что делать |
| --- | --- |
| **iPhone, iPad** | Открыть ссылку в Safari → «Поделиться» → «На экран “Домой”» → «Добавить» |
| **Android** | Открыть в Chrome → меню из трёх точек → «Установить приложение» |
| **Компьютер** | Chrome или Edge → значок установки справа в адресной строке |
| **APK-файл** | Actions → «Сборка Android APK» → Run workflow → скачать `iai-club-apk` |

Внутри приложения то же самое написано на экране **Профиль → Установить на телефон**:
там же появляется системная кнопка установки, когда браузер её предлагает.

APK нужен, если хочется именно файл приложения — например, раздать участникам
напрямую. Он собирается через Capacitor тем же кодом, что и сайт, и подписан
отладочным ключом, поэтому на телефоне надо разрешить установку из неизвестных
источников. Для App Store и Google Play понадобятся аккаунты разработчика и
подпись релизным ключом — это следующий шаг, а не первая версия.

## Что уже работает

| Раздел ТЗ | Что можно потрогать |
| --- | --- |
| **Вход** | Телефон и код, три обязательных поля (имя, город, чем занимаетесь), выбор пакета. Без активной подписки — экран «Оплатите, чтобы войти» |
| **Главная** | Полоса сезона, ближайшее событие с «Иду» / «Не могу», город, место команды в рейтинге, пара недели, последнее видео, слёт, приглашение друга |
| **Расписание** | События на месяц вперёд по неделям, фильтры, счётчики «идут N человек», аватарки, «Подключиться» за 15 минут до начала, записи прошедших встреч |
| **Города** | Двое в городе → сам создаётся чат, в расписании появляется еженедельная «Пятница в {городе}», обоим приходит уведомление, первому предлагается стать организатором. Организатор задаёт место, время и может отменить конкретную неделю; без организатора любой участник предлагает место |
| **Команды** | Создание, открытые команды, заявки, ответ капитана, состав от 3 до 10 человек, роли, недельный отчёт, командный созвон, чат |
| **Рейтинг** | Внесение выручки (сумма, за что, скриншот, сэкономленные часы), правка 48 часов, копилка 10%, «не засчитано» пока взнос не отмечен, общий счётчик копилки сезона |
| **База знаний** | Поиск, фильтры по типу и теме, превью и переход на внешнее видео, отметка «просмотрено» только для себя, архив прошлых сезонов за 990 ₽ |
| **Люди** | Каталог с фильтрами по городу, навыку и пакету, «Написать» в телеграм, друзья с заявками, лента друзей, друзья видны в расписании |
| **Рандом-кофе** | Пара недели с приоритетом «один город, разные команды, ещё не встречались», кнопки «Договорились» и «Пропустить», выключается одним переключателем |
| **Большой слёт** | Появляется за месяц до выпускного: дата, место, программа по часам, «Буду», список едущих, что взять |
| **Рефералка** | Личная ссылка, кнопка «Поделиться», готовый текст и картинка для сторис, счётчики переходов и оплат, бонусный счёт, история |
| **Профиль** | Фото, имя, город, чем занимаюсь, что ищу, ссылки, навыки, пакет и дата следующего списания, три переключателя, выход |
| **Уведомления** | Пятница, ссылка на онлайн за час, пара недели, «в вашем городе теперь двое», новое видео, «вас обошли», «покажи, что сделал». Плюс системные пуши, если разрешить |
| **Админка** | `#/admin`, пароль `club2026`: участники и доступы, события, база знаний, копилка, города, рассылка, выгрузка в CSV |

## Чего нет и почему

- **Сервера и базы данных.** Всё живёт в `localStorage` телефона: у каждого свои
  данные, очистка данных браузера их сбрасывает. Где подключать настоящий бэкенд —
  описано ниже.
- **Настоящей авторизации.** Код из СМС не проверяется, подойдёт любой.
- **Оплаты внутри.** По ТЗ оплата идёт снаружи, приложение только читает статус
  подписки. Кнопка «Я оплатил» в демо просто открывает доступ.
- **Личных сообщений.** Кнопка «Написать» ведёт в телеграм — так и задумано.
- **Своего видеохостинга.** Только ссылки на YouTube, Kinescope, VK Видео, Google Drive.

**Демо-условность, о которой стоит знать:** в одиночном демо некому нажать кнопку
за другого, поэтому капитан отвечает на заявку в команду через 15 секунд, а заявку
в друзья демо-участник принимает через 10. С настоящим бэкендом это делают живые люди.

## Демо-данные

33 вымышленных участника в 10 городах, 5 команд, записи о выручке, 17 материалов
базы знаний и расписание на два месяца. Сезон всегда считается от сегодняшней
даты, поэтому демо не устаревает. В Алматы намеренно оставлен один участник —
зарегистрируйтесь там, чтобы увидеть, как срабатывает правило «в городе стало двое».

Кнопка **Посмотреть как участник клуба** на экране входа пускает внутрь под любым
из демо-участников — так видно команду, рейтинг и друзей изнутри.
Сбросить всё: Профиль → «Сбросить демо-данные».

## Как запустить локально

```bash
npm install
npm run dev:club     # http://localhost:5174/evaspace/club/
npm run build:club   # сборка в dist/club/
```

Иконки приложения рисуются кодом: `npm run icons:club`.

```
club/
├─ index.html            оболочка страницы
├─ public/               манифест, service worker, иконки
├─ tools/make-icons.mjs  генератор иконок (PNG рисуется вручную, без зависимостей)

   ├─ lib/

   │  ├─ seed.js         сборка демо-базы от сегодняшней даты
   │  ├─ logic.js        правила клуба: видимость событий, рейтинг, копилка, кофе, города
   │  ├─ events.js       повторяющиеся серии событий (эфиры, пятницы, созвоны)
   │  ├─ time.js         даты и русские формулировки времени
   │  ├─ format.js       деньги, склонения, выгрузка CSV
   │  ├─ video.js        превью и определение сервиса по ссылке
   │  ├─ image.js        сжатие скриншотов перед сохранением

   ├─ components/        общие элементы, иконки, карточка события, нижнее меню

```

## Куда подключать настоящий бэкенд

Вся работа с данными идёт через один редьюсер в `src/lib/store.jsx`: экраны
только читают состояние и отправляют действия. Чтобы перевести приложение на
Supabase или любой другой бэкенд, достаточно:

1. Заменить `load()` и `save()` на запросы к базе — имена таблиц и полей совпадают
   с моделью данных из ТЗ (`users`, `cities`, `events`, `rsvp`, `teams`,
   `team_members`, `team_requests`, `revenue_entries`, `contributions`,
   `materials`, `friendships`, `coffee_matches`, `referrals`).
2. Перенести на сервер три правила из `src/lib/logic.js`: `ensureCityRules`
   (двое в городе), `ensureCoffee` (пары по понедельникам) и `buildNotifications`
   (рассылка). Сейчас они честно считаются в браузере.
3. Заменить демо-вход в `src/screens/Auth.jsx` на настоящую отправку кода.

Расчёт рейтинга и копилки (`teamStats`, `leaderboard`) переносить не нужно —
это чистые функции, они одинаково работают и на клиенте, и на сервере.
