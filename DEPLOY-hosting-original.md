# Eva Space — установка на Beget

## Что делать по шагам

### 1. Загрузить файлы
Панель Beget → «Файловый менеджер» → папка вашего домена (обычно `public_html`).
Загрузите туда всё содержимое архива. Можно закинуть архив целиком и распаковать на месте.

Должно получиться так:

```
public_html/
  index.html      приложение
  api.php         сервер: сохранение данных и загрузка файлов
  check.php       страница самопроверки (удалите после настройки)
  manifest.json   описание приложения для телефона
  sw.js           офлайн-режим
  icon.svg, icon-192.png, icon-512.png
  .htaccess
  data/           хранилище — здесь лежит весь контент
  uploads/        загруженные фотографии
```

### 2. Открыть проверку
Зайдите на **вашсайт.ру/check.php** — страница покажет список из тринадцати пунктов.
Всё, что отмечено красным, нужно исправить: рядом написано, как именно.

### 3. Права на папки
Если красным отмечены `data` или `uploads`: в файловом менеджере правой кнопкой по папке →
«Права доступа» → поставить **755**. Если не помогло — **775**.

### 4. Сменить ключ синхронизации
Это обязательно, иначе контент платформы сможет переписать любой человек.

- В файле `api.php` найдите строку `const ADMIN_KEY = 'eva-change-me';` и впишите свой ключ
- В файле `index.html` найдите строку `const SYNC_KEY = 'eva-change-me';` (она в самом начале блока
  синхронизации, с пояснением) и впишите **тот же самый** ключ

Ключ — любая строка без пробелов, например `eva-2026-mySecret47`.
После замены обновите `check.php` — пункт про ключ станет зелёным.

### 5. Включить HTTPS
Панель Beget → «Домены и поддомены» → бесплатный сертификат Let's Encrypt.
Без HTTPS приложение не установится на телефон — это требование браузеров.

### 6. Удалить check.php
После того как все пункты зелёные — удалите файл `check.php` из папки сайта.

## Как проверить, что всё работает

1. Откройте сайт, нажмите внизу «Вход для администраторов и экспертов», войдите
2. В шапке панели появится строка **«Данные сохраняются на сервере»** с зелёной точкой.
   Если она красная или написано «локальный режим» — нажмите на неё, откроется диагностика
3. Добавьте материал: обложку, ссылку на видео, теги
4. **Обновите страницу** — материал должен остаться
5. Откройте сайт в другом браузере или на телефоне — материал должен быть виден там же

## Что где хранится

**Общее для всех** — в файле `data/db.json`: материалы, курсы с уроками и модулями, мероприятия,
товары, профили экспертов, очередь модерации, заказы, вопросы о товарах, обращения в поддержку,
послания в сообществе.

**Фотографии** — отдельными файлами в папке `uploads/`. Браузер сжимает снимок до 1400 px
и качества 86%, отправляет на сервер, а в базе остаётся только короткая ссылка.
Поэтому база не разрастается и не упирается в лимиты хостинга.

**Личные данные** пользовательницы — прогресс, баллы, программа, сообщения — хранятся в её браузере
и дублируются на сервер по адресу почты. При входе с другого устройства подтягиваются обратно.

**Если сервер недоступен** (например, открыли `index.html` двойным кликом), приложение честно
пишет «локальный режим» и продолжает работать — но данные видит только тот, кто их создал.

## Резервная копия

В панели администратора: строка состояния сверху → «Скачать резервную копию».
Получите файл со всей базой. Отдельно скачивайте папку `uploads/` — это фотографии.

Восстановление: положить `db.json` обратно в `data/`, а файлы — в `uploads/`.
Сервер сам делает копию `data/db.backup.json` перед каждой записью, так что при сбое данные не теряются.

## Приложение на телефоне

При заходе с телефона внизу появляется полоса «Установить Eva Space».
На Android установка в один тап. На iPhone откроется инструкция: «Поделиться» → «На экран Домой».
После установки приложение открывается без адресной строки, с иконкой-звездой и работает без интернета.

---

## Что убрать перед показом пользователям

Внизу экрана есть переключатель ролей «Пользователь / Эксперт / Админ» — это инструмент разработки.
Чтобы убрать: откройте `index.html`, найдите в функции `render()` строку с `roleSwitch()` и удалите её.

## Ограничения этого решения

Хранение в JSON-файле рассчитано на демо и первые сотни пользователей. Когда активных станет
больше тысячи, одновременные записи начнут конфликтовать — тогда данные переносятся в MySQL,
которая уже входит в тариф Beget. Переписывается только `api.php`, приложение менять не придётся.

Загрузка одного файла ограничена настройкой хостинга `upload_max_filesize` (обычно 2–8 МБ).
Фотографии сжимаются автоматически и укладываются в лимит. Видео на сервер не загружаются —
для них вставляется ссылка на YouTube, Vimeo, Kinescope или прямой файл.
