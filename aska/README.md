# АСЬКА

Олдскульный мессенджер в духе ICQ — папка `aska/`, без сборки: HTML + CSS + JS.

| Версия | Адрес | Что это |
| --- | --- | --- |
| **3** | https://emorozoff.github.io/evaspace/aska/ | новый дизайн «Aero 2007» для зумеров и миллениалов: стекло, пузыри, нижняя навигация, музыка и кино как в стримингах, свайп-знакомства, обученный аватар |
| **v2** | https://emorozoff.github.io/evaspace/aska/v2/ | классика: все фишки v2 в серых окнах Win98 |
| **v1** | https://emorozoff.github.io/evaspace/aska/v1/ | простая и понятная: контакты, беседы, «о-оу», смайлы, Аська и друзья |
| промо | https://emorozoff.github.io/evaspace/aska/promo/ | слайды «10 преимуществ» |

Все версии живут в одном браузере и видят одни и те же номера и переписку.

## v2 — что умеет

| Что | Как |
| --- | --- |
| Регистрация | телефон + ник (+ пароль) → шестизначный номер; поле «Код друга» для реферала |
| Аська | лучший друг: знакомится, помнит ответы, советует, шлёт открытки, ведёт досье |
| Друзья | Катюха_98, ha©keR_Vova, DJ_Serёga, Ленка_Питер, Макс_Философ и **Батя** — цифровой отец: сынок/дочка, советы по теме, редко пишет сам, но присылает открытки |
| Аватар КИРР | твой цифровой двойник. Учится сам на переписке: берёт манеру (регистр, смайлы, «)))», вводные слова, обращения), банк твоих фраз и пары «что тебе написали → что ты ответил», и отвечает друзьям твоими настоящими словами. Знает всех друзей по кругам, где ты (по «Я лечу»), чем занят (статус, музыка, кино), вкусы, холодильник, мероприятия. Окно «Контакты → Мой аватар: обучение»: обученность, манера, что знает, фразы; тренировка («учись» в беседе — вопросы-ответы), «запомни: …», разбор реплик, на которые не нашёлся. Телефон не выдаёт |
| Пригласить друга | «Добавить контакт → Пригласить друга» (или меню «Контакты»): ссылка и код, имя и телефон друга. Когда друг регистрируется по коду или с этим телефоном, аватар сам встречает его: приветствие твоими словами, где ты и чем занят, открытка и песня, взаимные контакты, запись на твоей стене и сообщение тебе |
| Тишина | боты пишут редко: пауза между любыми сообщениями от 4 минут и растёт, если не отвечаешь; не больше двух неотвеченных, не пишут, пока ты печатаешь, пока вкладка в фоне — не больше одного; конверт мигает две минуты после сообщения, потом просто висит |
| Стена и интересы | стена с открытками, треками, лайками; интересы общие для всех — у каждого своя страница: кто создал, кто поддержал, люди, сообщества с собственной стеной |
| Радио | три станции из общей коллекции: Бали FM (лаунж, баллады), Ева Спейс (техно, 8 бит, евродэнс), Юхом Плюс (поп, рок, хиты) — у каждой джингл, ведущий «в эфире» и случайная ротация; можно подключить настоящий поток (mp3/aac) — его услышат все |
| Страница трека | обложка, история записи, НФТ-паспорт (номер, владелец, кто добавил), ценность в ⚡ (прослушивания + 5×♥ + 3×плейлисты + 2×записи + 8×подарки), цепочка владения (выпуск, подарки, лайки), стена трека с ответами автора и Винилла; свою историю дописывает тот, кто добавил |
| Люди | окно «Люди»: случайное знакомство с досье от Аськи и процентом совпадения, вкладка «По интересам», все люди сети; 10 новых людей с характером (Оксана_Travel, Димон_Тренер, Алиса_Книжная, Стас_Геймер, Марина_Шеф, Егор_Бизнес, Надя_Йога, Паша_Рыбак, Лиза_Дизайн, Тимур_DJ) — не в контактах, пока не познакомишься |
| Круги и режимы | «Близкие / Бизнес / Общение» меняют статус, цвет и порядок контактов |
| Мероприятия | «Позвать в гости»: дата, место, вход бесплатно или за баллы; приглашения в беседу с ответом «Приду / Может быть / Не смогу»; афиша, гости, мероприятия друзей |
| Рефералы | код и ссылка приглашения, цепочка в стиле блокчейна: кто кого позвал, 1-й/2-й/3-й круг, леджер блоков, уровни Новичок → Магнат связей, баллы +10/+5/+2 |
| Магниты | «Я лечу» → магнит страны на холодильник, друзьям по магниту; дарение НФТ-магнитов |
| Досье | Аська пишет досье: аватар и ник, увлечения, манера общения, вердикт; можно закрыть |
| Уровни | Обычная → Gold → Black за баллы: ободок цветочка, VIP-статусы, магнит с Луны |
| Винил | SVG-вертушка: пластинка с бороздками и этикеткой раскручивается и тормозит как настоящая, тонарм с противовесом сам опускается на дорожку и ползёт к центру по ходу трека; 12 хитов + общая коллекция по ссылкам (Яндекс Музыка, YouTube, SoundCloud, mp3); обложка у каждого трека; скин «ретро» / «киберпанк»; избранное, прогресс, повтор, случайный порядок; поделиться в беседу, на стену, ссылкой `?play=` |
| Винилл | консультант по музыке в контактах: «посоветуй», «включи …», «нравится / не нравится / удали», «мой вкус». Формирует вкус по лайкам и прослушиваниям, вычеркнутое не предлагает, от «вы» переходит к «дружище» |
| Кино | фильмы и сериалы по ссылке (YouTube, VK Видео, Rutube, Vimeo, Дзен, mp4) смотрятся прямо в АСЬКЕ с любого устройства; серии подряд, запоминает где остановился, ♥ любимое, «посоветовать» другу и на стену, рекомендации по вкусу и лайкам друзей, ссылка `?watch=`; друзья сами советуют кино |
| Холодильник | старый добрый «Холодок-99»: кремовый корпус, хромовая ручка, шильдик, ножки; дверца открывается в 3D — внутри морозилка, напитки, еда и овощной ящик с НФТ-баночками и бутылками; снаружи магниты из поездок: форма по стране, флаг, достопримечательность, номер НФТ, блик; магниты и еду можно дарить |
| Стена | публичная переписка: записи, открытки, треки, кино, комментарии; аватары и друзья отвечают; последние 6 записей + вся история; можно сделать приватной |
| Подсказки | при первом входе и в «Справка → Подсказки»; режим переключается списком сверху |
| Статусы | 18 занятий («в полёте», «создаю шедевр»…) плюс свой текст |

## Файлы

- `app.js` — окна, контакты, беседы, стена, профиль, магниты, досье, уровни, мероприятия, рефералы, аватар, винил-интерфейс
- `brain.js` — разговорный движок Аськи и друзей (намерения, память, пол, советы, воспоминания, без повторов) и движок аватара (стиль + цепочка слов). Никаких нейросетей — правила и характер
- `aero.css` — вид «Aero 2007», нижняя навигация, мини-плеер, экраны музыки, кино, людей и обучения аватара
- `v2/` — снимок классической версии 2
- `music.js` — секвенсор и синтезатор, внешние треки по ссылке (iframe / `<audio>`)
- `cinema.js` — разбор ссылок на видео, постеры, стартовая коллекция (открытые фильмы Blender Foundation и демо-ролики)
- `art.js` — цветочки, смайлы, открытки, магниты
- `sounds.js` — все звуки на лету
- `promo/` — промо-слайды; `v1/` — простая версия

Публикуется workflow `.github/workflows/aska.yml` в папку `aska/` ветки `gh-pages`, соседние приложения не трогает.
