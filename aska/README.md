# АСЬКА

Олдскульный мессенджер в духе ICQ 99/2000 — папка `aska/`, без сборки: HTML + CSS + JS.

**Открыть:** https://emorozoff.github.io/evaspace/aska/
**Промо-слайды:** https://emorozoff.github.io/evaspace/aska/promo/

| Что | Как |
| --- | --- |
| Регистрация | телефон + ник (+ пароль по желанию) → выдаётся шестизначный номер |
| Контакты | цветочки-статусы, круги «Близкие / Бизнес / Общение», режимы меняют статус и цвет окон |
| Звук «о-оу!» | на каждое входящее сообщение; синтезируется через Web Audio, файлов нет |
| Смайлы | 22 штуки, у каждого свой голос — звучит при вставке и при клике в переписке |
| Аська | лучший друг с номером 000001: знакомится, задаёт вопросы, помнит ответы, шлёт открытки со звуком, меняет статусы, ведёт досье; чего не знает — «это в платной версии» |
| Друзья | Катюха_98, ha©keR_Vova, DJ_Serёga, Ленка_Питер, Батя_в_сети, Макс_Философ — у каждого свой характер, манера письма, стена и холодильник |
| Стена | записи, открытки, треки и плейлисты, лайки; видна друзьям |
| Профиль | аватар, интересы, процент совпадения, прикольные статусы («в полёте», «создаю шедевр»…), случайное знакомство |
| Магниты | «Я лечу» → магнит страны на холодильник, друзьям по магниту в беседу; магниты можно дарить (НФТ с номером) |
| Досье | Аська пишет досье на каждого: аватар и ник, увлечения, манера общения, вердикт; можно закрыть от друзей |
| Уровни | Обычная → Gold → Black за баллы: золотой/чёрный цветочек, VIP-статусы, магнит с Луны |
| Винил | 12 хитов конца девяностых, синтезируются из нот; плейлисты, «поделиться» в беседу и на стену |
| Переписка | между вкладками одного устройства (BroadcastChannel + localStorage) |
| Телефон | добавь на экран «Домой» — работает как приложение, офлайн тоже |

## Файлы

- `app.js` — окна, контакты, беседы, стена, профиль, магниты, досье, уровни, винил-интерфейс
- `brain.js` — разговорный движок Аськи и друзей: намерения, память, вопросы, открытки, статусы. Никаких нейросетей — правила и характер
- `music.js` — секвенсор и синтезатор: ударные, бас, соло, подклад, шипение пластинки
- `art.js` — векторные цветочки, смайлы, открытки и магниты
- `sounds.js` — все звуки синтезируются на лету
- `promo/` — промо-слайды «10 преимуществ» в формате приложения

Публикуется workflow `.github/workflows/aska.yml` в папку `aska/` ветки `gh-pages`, соседние приложения не трогает.
